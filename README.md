# Project Riser 🚀
*The Ultimate Developer Resurrection Tool - V7*

Project Riser is an enterprise-grade, privacy-first, in-memory analysis tool designed to help developers revive abandoned GitHub repositories and connect them with their past AI conversations.

## New in V7: Graveyard Analytics
A highly visual, exportable dashboard summarizing your entire repository graveyard. Perfect for sharing on Reddit or Twitter.
- **Coma Index:** Classifies projects based on the time since the last commit (Fresh Dead, Decomposing, Skeleton, Fossil).
- **Mental Debt & Mood X-Ray:** Analyzes commit messages to estimate the emotional state you were in when you abandoned the project.
- **AI Corpus Match Score:** Rates how much untapped knowledge exists in your chat history for a given project.
- **Resurrection Cost (T-Shirt Sizing):** An aggregated view of how much effort it will take to revive your projects.
- **Screenshot Exporter:** Built-in tool to instantly generate a clean PNG of your Graveyard Analytics.

## Setup
1. Run `docker-compose up --build`.
2. Open `http://localhost:5000`.
3. Enter your GitHub PAT and Ollama URL in the Settings.
